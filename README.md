# Cashback Merge

Мини-игра в духе 2048 с плитками кэшбэка на поле 4×4.

В МР1 реализованы загрузка и проверка JSON-конфига, состояние игры,
создание двух стартовых плиток по seed и текстовый вывод поля.
Вероятности хранятся в `BigDecimal`. Одинаковый конфиг и seed дают одинаковое стартовое поле.

В МР2 реализованы ходы `UP`, `DOWN`, `LEFT`, `RIGHT`, сдвиг и слияние плиток.
Одна плитка сливается максимум один раз за ход. После успешного хода появляется
ровно одна новая плитка и расходуется один ход. Ход без изменений отклоняется
исключением, не расходует ход и не создаёт плитку.

Score начинается с нуля и увеличивается на значение каждой полученной при слиянии
плитки: `2 + 2 → 4` даёт 4 очка. Сдвиг и появление плитки очков не дают.
После исчерпания лимита новые ходы запрещены; достижение `32%` игру не завершает.
Случайное появление плиток находится в `GameSession`, логика слияния - в `GameState`.

## Запуск

Нужен JDK 25 или новее. Команды для Windows:

```powershell
.\gradlew.bat run
.\gradlew.bat run --args="42 config/campaign.example.json"
```

Аргументы: seed и путь к конфигу. По умолчанию используются `42` и `config/campaign.example.json`.
Команда выводит стартовое поле. Для выполнения ходов используется
`GameSession.applyMove(Move.LEFT)` и остальные значения `Move`.
